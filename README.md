<h1>Microsoft Office 365 Troubeshooting Within An Azure Virtual Machine</h1>
This project demonstrates common Office 365 troubleshooting scenarios encountered in IT support roles. All scenarios were performed within a Windows Azure Virtual Machine simulating an enterprise end-user workstation.<br />


<h2>Environments and Technologies Used</h2>

- Microsoft Azure (Virtual Machines/Compute)
- Remote Desktop (RDC/Windows App)
- Microsoft 365 Applications(OneDrive, Sharepoint)
- Browser-based troubelshooting

<h2>Operating Systems Used </h2>

- Windows 11 (21H2)

<h2>List of Prerequisites</h2>

- Basic/General Understanding of Microsoft Azure
- Azure Subscription/Azure Account(Portal) created
- Resource Group created within your Azure portal
- Windows 11 Virtual Machine(Windows) created within your Azure portal with the resource group you've created previously
